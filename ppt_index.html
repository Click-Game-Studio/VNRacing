Phần còn lại là Markdown thuần. Starlight tự render thành HTML với navigation.

Configuration

Thanh điều hướng & Version

NAVIGATION

File sidebars.ts khai báo cấu trúc thanh bên. Thêm mục mới = thêm entry trong này.

sidebars: [
  { label: 'Tổng quan', items: ['intro', 'overview'] }
]
VERSION SWITCHER

Cấu hình version trong astro.config.mjs. Thêm version mới = thêm entry, kết quả xuất hiện ngay trên switcher.

versions: [
  { slug: 'current', label: 'Hiện tại' },
  { slug: 'v2.0', label: 'Tính năng mới' }
]

C4 Model

Tác nhân → Quan hệ → Góc nhìn

Ba tầng của C4: định nghĩa actor khởi đầu, xây dựng mô hình quan hệ, tạo góc nhìn.

TẦNG 1
Tác nhân

Khai báo person, system, container — ai và cái gì tham gia hệ thống.

TẦNG 2
Quan hệ

Xác định cách các tác nhân tương tác — gọi API, gửi event, đọc/ghi DB.

TẦNG 3
Góc nhìn

Tạo view: context → container → component. Mỗi view sinh diagram tự động.

LikeC4 code → diagram SVG tương tác. Sửa code = diagram cập nhật.
