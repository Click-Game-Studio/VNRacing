## Đã triển khai

### Matchmaker V6
UMatchServiceSubsystem với MMR widening windows (±500/±1000/±1500), CR threshold widening (3 + (Elapsed/3)\*3), timeout 60s. Ping đang là placeholder 50ms.

### MMR Profile
Go runtime RPC `prototype_get_multiplayer_profile` (get/init MMR=300) và `prototype_update_mmr_result` (win/loss/quit/disconnect ±30). Leaderboard mirror.

### Edgegap Broker
Nakama Go runtime: RegisterMatchmakerMatched → create handoff match → allocate Edgegap → broadcast opcode 1 (host:port+token). Cleanup grace 600s.

### Waiting Room
AMultiplayerWaitingRoomGameMode: Join-token validation, expected-players wait, ServerTravel to race map.

### UI Widget
UMultiplayerMatchmakingWidget state machine: Idle→Loading→Ready→Searching→Matched→Joining→ServerReady→Traveling, Error/TimedOut branches.
