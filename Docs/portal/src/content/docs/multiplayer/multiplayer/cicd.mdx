## Current CI/CD Status

Pipeline hiện tại (RacingMobile.groovy) chỉ build iOS + Android:

- Perforce checkout
- Build editor (iOS + Android)
- Android: internal artifact → Nexus; Shipping AAB → Google Play
- iOS: package → xcarchive → TestFlight upload
- Discord notifications

**Chưa có stage nào** cho LinuxServer + Edgegap publish + Docker image push.

## New Stage: LinuxServer / Edgegap Publish

Stage mới chạy **song song** với iOS và Android. Dùng `Build/Edgegap/publish_edgegap_server.sh`.

### Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| LINUXSERVER_MODE | choice | skip | LinuxServer build mode: skip, package, publish |
| EDGEGAP_VERSION | text | (auto) | Edgegap version tag. Auto: `<app>-<yyyymmdd>-r<P4_CL>` |
| EDGEGAP_DRY_RUN | boolean | true | Nếu bật, chỉ dry-run, không push thật |

### Environment variables needed

| Variable | Source | Description |
|---|---|---|
| LINUX_MULTIARCH_ROOT | env | UE5 Linux cross-compile toolchain path |
| EDGEGAP_API_TOKEN | credentials | Edgegap API token |
| EDGEGAP_CONTAINER_REGISTRY_PROJECT | credentials | Container registry project |
| EDGEGAP_PRIVATE_REGISTRY_USERNAME | credentials | Registry username |
| EDGEGAP_PRIVATE_REGISTRY_TOKEN | credentials | Registry token |
| UE5_LINUX_EXE | env | Optional: Linux UnrealEditor-Cmd override |
