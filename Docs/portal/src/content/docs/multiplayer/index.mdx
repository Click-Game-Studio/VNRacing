## Stack tổng thể

| Layer | Công nghệ | Trạng thái |
|---|---|---|
| Client | UE5 (PrototypeRacing) | ✅ |
| Nakama SDK | Plugins/Nakama 2.10.1 | ✅ |
| Nakama Server | 3.39.0 + Postgres 16.8 (Docker) | ✅ |
| Go Runtime | prototype_get_multiplayer_profile, prototype_update_mmr_result | ✅ |
| Matchmaking V6 | MMR widening ±500/±1000/±1500, CR widening, 60s timeout | ✅ |
| Edgegap Broker | RegisterMatchmakerMatched → handoff → allocate → opcode 1 | ✅ |
| Dedicated Server | AMultiplayerWaitingRoomGameMode, join-token, ServerTravel | ✅ |
| Client UI | UMultiplayerMatchmakingWidget state machine | ✅ |
| CI/CD publish | publish_edgegap_server.sh (local validated) | ✅ |
| **Server-authoritative race** | Race result do server phê duyệt | ❌ |
| **UX Scenes** | Intro/Quick/Post-game scenes | ❌ |
| **Lobby / Private Match** | 4 US Lobby Match | ❌ |
| **AI Takeover** | Chạy giúp khi disconnect | ❌ |
