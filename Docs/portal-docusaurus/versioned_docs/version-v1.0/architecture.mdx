# Kiến trúc (sơ đồ C4)

Các sơ đồ C4 dưới đây sinh từ mô hình nguồn duy nhất (LikeC4) và **xuất PNG tại
bước build** — hiện tức thì, không cần tải engine phía client. Cùng mô hình với
portal cũ; chỉ khác là tĩnh.

:::tip[Lối tắt cho dev]
Mỗi sơ đồ có **link tới trang Thiết kế chi tiết (LD)** ngay bên dưới. Bản
Astro/LikeC4 cho bấm thẳng vào ô trên sơ đồ; bản tĩnh này thay bằng link văn bản
để giữ tốc độ và đơn giản.
:::
